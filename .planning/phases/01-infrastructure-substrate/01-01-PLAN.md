<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Developer host ↔ containers | Local-dev only; services exposed on localhost, no external network |
| kafka ↔ kafka-init | Init container runs as root in the bitnami image; executes topic-creation script |
| MinIO admin creds | Default `minioadmin`/`minioadmin` is dev-only; NEVER used in staging or production |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | docker-compose.yml default credentials | accept | Local-dev scope only; README.md calls out that these creds are dev-only. Production Helm chart (Phase 7) uses External Secrets Operator + Vault (STACK.md Layer 8). |
| T-01-02 | Tampering | Kafka topic auto-create allowed | mitigate | Set `KAFKA_CFG_AUTO_CREATE_TOPICS_ENABLE=false` so only `create-topics.sh` can create topics; prevents a rogue producer from silently creating a parallel audit topic. |
| T-01-03 | Tampering | HIPAA audit stream contamination | mitigate | `ndr.audit` has a reserved consumer group name `ndr-audit-cg` documented in `infra/kafka/README.md` and enforced in Plan 3's audit-router config. Any observability consumer group joining `ndr.audit` is flagged as an architectural violation in code review. |
| T-01-04 | Denial of Service | Unbounded Kafka message size | mitigate | Default broker `message.max.bytes` (1 MB) is left at default; documented in README as the per-record ceiling to prevent one tenant's oversized payload from stalling partitions. |
| T-01-05 | Repudiation | kafka-init script runs non-idempotently | mitigate | `--if-not-exists` on every `kafka-topics.sh --create` call; script is idempotent and safe to re-run on `docker compose up`. |
| T-01-SC | Tampering | npm/pip/cargo installs | mitigate | No package-manager installs in this plan (pure container images and bash scripts). Image tags are pinned (`bitnami/kafka:3.7`, `postgres:16-alpine`, `minio/minio:latest` — note: `latest` is a local-dev convenience and MUST be replaced with a pinned digest before any shared-environment deployment; flagged in Plan 3 reconciliation). |
</threat_model>
